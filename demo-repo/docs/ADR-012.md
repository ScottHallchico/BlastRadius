# ADR-012: Event-Driven Order Notifications

Date: 2024-03-15

## Context
Order creation is slow because we synchronously send emails.

## Decision
We will use Redis Pub/Sub (`order-events` channel).
`OrderService` will publish. `NotificationService` will subscribe.

## Invariants
- The schema of `ORDER_CREATED` must remain backward compatible.
- If we ever move away from Redis, we must ensure all active consumers (currently just NotificationService) are migrated, as this dependency is not visible in standard import graphs.
